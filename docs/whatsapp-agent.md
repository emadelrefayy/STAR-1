# WhatsApp AI Agent

## الفكرة
عملاء العميل (المرضى/الزباين) بيتواصلوا مع الـ Agent عن طريق واتساب مباشرة، من غير أي لوجين أو تطبيق.

## التدفق العام
1. رسالة العميل بتوصل لرقم واتساب بيزنس بتاع العيادة/المعمل
2. الرسالة بتتوجّه لـ n8n webhook
3. n8n بيحدد نوع الطلب:
   - حجز ميعاد جديد (dental) → يتفتح جدول الدكاترة، يقترح مواعيد متاحة
   - استعلام عن حالة تحليل (lab) → يدور في lab_test_orders بالاسم/الرقم
   - سؤال عام → رد تلقائي من الـ AI agent
4. الرد بيرجع للعميل على نفس محادثة الواتساب

## البيانات المطلوبة
- ربط كل tenant برقم واتساب بيزنس خاص بيه (أو رقم مركزي + تمييز حسب الرقم المرسل له العميل)
- تسجيل كل محادثة في جدول chatbot_leads (موجود في الـ core)

## ملاحظة
التنفيذ الفعلي للـ Agent (workflow n8n + الربط بواتساب بيزنس API) هيبقى خطوة منفصلة بعد ما نخلص الداشبورد، لإنه محتاج حساب WhatsApp Business API فعلي.
