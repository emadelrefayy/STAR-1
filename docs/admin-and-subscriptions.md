# Super Admin & Subscriptions

## جدول super_admins
- id, email, full_name
- منفصل تمامًا عن staff_users بتوع العملاء (tenants)

## جدول subscriptions
- id, tenant_id, active_modules (array)
- status: active | expired | trial
- renewal_date
- plan/price

## صفحات Super Admin
1. **قائمة العملاء (Tenants)**: إضافة عميل جديد، تحديد الموديولات المفعّلة له
2. **إنشاء حسابات العميل**: بعد إضافة العميل، الأدمن بيعمل له:
   - username/password لداشبورد الاستقبال
   - username/password لداشبورد الدكتور/المدير
3. **متابعة الأداء**: عدد المواعيد/الطلبات لكل عميل، نشاط عام
4. **متابعة الاشتراكات**: مين مشترك، تاريخ التجديد، حالة الدفع
5. **صيانة**: تفعيل/تعطيل عميل أو موديول معين وقت الحاجة

## WhatsApp AI Agent (عملاء العميل النهائيين)
- مفيهوش لوجن خالص
- بيتواصل عن طريق n8n webhook مربوط برقم واتساب بيزنس بتاع كل عميل (أو رقم مركزي بيوجه حسب العميل)
- المهام: حجز ميعاد (dental) / استعلام عن حالة تحليل (lab) / رد على أسئلة عامة
